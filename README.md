# Guilherme Lourenço

> Application Security Engineer (AppSec) • DevSecOps • Java Backend • APIs & Microservices

Sou engenheiro de segurança de aplicações com background forte em desenvolvimento backend Java/Spring Boot e experiência prática construindo sistemas escaláveis, pipelines seguros e arquiteturas resilientes.

Minha atuação hoje gira em torno de AppSec e DevSecOps, aproximando engenharia e segurança através de práticas como:

- Secure SDLC
- Security by Design
- Shift Left Security
- Threat Modeling
- OWASP Top 10
- Hardening
- Segurança em APIs REST
- CI/CD Security
- Vulnerability Management

Tenho experiência trabalhando com microsserviços, automação de segurança em pipelines GitHub Actions, análise de vulnerabilidades, integração de ferramentas SAST/DAST/SCA e segurança em ambientes Docker/Kubernetes.

Além da parte técnica, também possuo foco em governança e conformidade, com formação em Defesa Cibernética e pós-graduação em Direito Digital.
